# Templar showcase notes

These three ordinary Markdown notes are the sources for the gallery in the project README:

- `Botanical Field Notes.md` — editorial field journal with a warm botanical treatment.
- `Alpine Field Log.md` — cool travel log with route data and field callouts.
- `Neon Night Brief.md` — dark creative brief with high-contrast cyan and magenta accents.

Each note demonstrates headings, emphasis, highlights, images, tables, lists, tasks, callouts, and dividers; the neon note also includes a fenced code block. Copy the entire `Templar Showcase/` folder into a vault, then apply any Templar style you want—the included `Assets/` layout already matches every image embed.

For `1.2.0-alpha.1`, the dividers are also useful baseline checks: in a strict or balanced ruled/graph style, each rendered horizontal rule should consume one complete grid row and every following paragraph should remain aligned. The same notes can be searched/previewed from Page Styles without modifying their persisted style until Apply is selected, and paged variants can be sent through **Templar: Print / export styled note**.

The three showcase images are original project artwork generated with OpenAI's built-in image generation tool for this release. They contain no third-party logos or readable text.
